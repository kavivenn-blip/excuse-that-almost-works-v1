One excuse a gamer texts the boss to skip work during GTA 6 launch week, written by a program, for make.fun's "The Excuse That Almost Works" bounty: one line of plain text, at most 20 words, judged two at a time by a house judge playing a tired manager who believes almost none of them.

## Run it

```sh
python3 main.py
```

The program writes one line to `/output/entry.txt` (77 characters, 16 words, UTF-8, no trailing newline). Deterministic: two runs from a clean copy produce byte-identical output. No network, no dependencies, no files outside this repository.

## The line

> Been up all night with the baby, she's finally asleep on me and I can't move.
